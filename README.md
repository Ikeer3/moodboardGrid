# 🖥️ Práctica: Moodboard Web Personal

## 📖 Descripción del Proyecto

Este repositorio contiene el código de mi moodboard web personal, diseñado y desarrollado como parte de mis prácticas y ejercicios de la asignatura Lenguaje de Marcas.

El objetivo principal de este proyecto ha sido aplicar y consolidar conceptos avanzados de diseño web moderno, creando una interfaz atractiva, funcional y **100% responsive**. Para ello, se ha implementado un diseño modular tipo "Bento Box" con temática deportiva, que sirve como escaparate para presentar mi perfil profesional, mi formación y mis habilidades técnicas mediante interacciones fluidas y efectos 3D.

## 🛠️ Tecnologías Utilizadas

Para la construcción de este proyecto se han empleado exclusivamente tecnologías nativas, sin depender de librerías ni frameworks externos, garantizando así un código limpio y ligero:

* **HTML5:** Para una estructuración semántica y accesible de todo el contenido.
* **CSS3:** Para el diseño visual, uso de variables nativas, animaciones, transiciones suaves y efectos modernos (físicas 3D y botones multicapa).
* **CSS Grid:** Como motor principal de maquetación para construir la estructura "Bento Box" y adaptar el layout a cualquier resolución de pantalla.
* **Flexbox:** Para la distribución dinámica y alineación interna precisa de los elementos dentro de cada tarjeta.
